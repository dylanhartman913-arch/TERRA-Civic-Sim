# Data Directory

`data/raw/` and `data/processed/` are excluded from version control (see `.gitignore`).
This file documents what lives in each directory, how to obtain it, and the notebook
execution order required to regenerate all derived outputs.

### Manual downloads required

These files cannot be fetched programmatically (JavaScript-gated portals, HIFLD login walls,
or scanned PDFs). Download them once and place in the paths shown.

| Path | Source | URL / Instructions |
|---|---|---|
| `ba_shapefiles/Balancing_Authorities.geojson` | HIFLD Open Data — Electric Power Transmission Lines | `https://hifld-geoplatform.opendata.arcgis.com/datasets/geoplatform::balancing-authority-areas` → Export as GeoJSON. No account required. |
| `census_counties/tl_2023_us_county.shp` (+ sidecar files) | US Census TIGER/Line 2023 — Counties | `https://www.census.gov/cgi-bin/geo/shapefiles/index.php` → Year 2023 → Counties → Download national file → unzip into `data/raw/census_counties/` |
| `census_tracts/mw_tracts_2020.parquet` | Census TIGER/Line 2020 Tracts — Mountain West states | See `08c_spatial_hierarchy.ipynb` Cell 2 for the bounding-box filter. Download the 11-state collection from `https://www.census.gov/geographies/mapping-files/time-series/geo/tiger-line-file.html` and convert to parquet with geopandas. |
| `ecoregions/us_eco_l3_state_boundaries.*` | EPA Level III Ecoregions | `https://www.epa.gov/eco-research/level-iii-and-iv-ecoregions-continental-united-states` → Download "Ecoregions of the Conterminous US (Level III)" shapefile. Place all sidecar files together. |
| `wy_fiscal/` (all PDFs + extracted CSVs) | Wyoming DOR Annual Reports | See `data/processed/MANUAL_FETCH.md` for the full item list and URL paths. PDFs are WY DOR fiscal year publications; extracted CSVs were produced with Tabula. Four items remain outstanding as of 2026-07-03. |

### E4ST solves (Julia)

After step 13, the E4ST grid model can be solved:

```bash
cd julia/
julia --project run_scenario.jl baseline
julia --project run_scenario.jl carbon_tax_50
julia --project run_scenario.jl ira_itc
julia --project run_scenario.jl carbon_tax_ira
```

Results land in `data/processed/e4st_results_v2/<scenario>/<timestamp>/`. The summary
JSONs under `data/processed/e4st_results/<scenario>/summary.json` are small enough to
commit and are tracked in version control via the terra-app data bundle.

## Environment Variables

Create `.env` (never committed) in the project root:

```
NREL_API_KEY=your_key_here        # https://developer.nrel.gov/signup/
CENSUS_API_KEY=your_key_here      # https://api.census.gov/data/key_signup.html
```

Both APIs are free. The NREL key is required for `01_eia_pull.ipynb` (PVWatts + Wind Toolkit).
The Census key is optional but raises rate limits in `08b_ees_baseline.ipynb`.
