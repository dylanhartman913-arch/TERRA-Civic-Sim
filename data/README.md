# Data Directory

This file describes what lives in `data/raw/` and `data/processed/`, how to obtain
source data, and which notebooks generate each derived file.

For a complete runtime file inventory with tracking status, hashes, and pipeline
assignments, see `docs/PIPELINES.md`.

### E4ST solves (Julia)

After the notebook pipeline, the E4ST grid model can be solved:

```bash
cd julia/
julia --project run_scenario.jl baseline
julia --project run_scenario.jl carbon_tax_50
julia --project run_scenario.jl ira_itc
julia --project run_scenario.jl carbon_tax_ira
```

Results land in `data/processed/e4st_results_v2/<scenario>/<timestamp>/`.

## Environment Variables

Create `.env` (never committed) in the project root:

```
NREL_API_KEY=your_key_here        # https://developer.nrel.gov/signup/
CENSUS_API_KEY=your_key_here      # https://api.census.gov/data/key_signup.html
```

Both APIs are free. The NREL key is required for `01_eia_pull.ipynb` (PVWatts + Wind
Toolkit). The Census key is optional but raises rate limits in `08b_ees_baseline.ipynb`.
